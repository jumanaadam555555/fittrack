# تمريني · FitTrack

تطبيق PWA بالعربية لتسجيل الحديد (السبت والثلاثاء)، السكواش (الاثنين والخميس)، الوزن، ومتابعة التقدم.

## نشر مجاني على GitHub Pages
1. أنشئي مستودع GitHub **عام** جديد باسم `fittrack`.
2. ارفعي **محتويات هذا المجلد** إلى جذر المستودع، بحيث يكون `index.html` في الجذر.
3. افتحي **Settings → Pages → Build and deployment → Deploy from a branch**.
4. اختاري `main` و `/(root)` ثم **Save**.
5. بعد النشر افتحي `https://USERNAME.github.io/fittrack/` (استبدلي USERNAME باسم حسابك).
6. على iPhone: افتحي الرابط في Safari → مشاركة → إضافة إلى الشاشة الرئيسية. على Android: Chrome → ⋮ → تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.

## الخصوصية والنسخ الاحتياطية
- تحفظ البيانات باستخدام `localStorage` على نفس الجهاز والمتصفح فقط، ولا ترفع السجلات إلى GitHub.
- سجلاتك **لا تتزامن** بين الأجهزة، وقد تختفي إذا مسحتِ بيانات الموقع أو غيرتِ الجهاز. استخدمي **تنزيل نسخة احتياطية** دوريًا ثم **استعادة نسخة** عند الحاجة.
- لا تضعي ملفات النسخ الاحتياطية JSON في المستودع العام.
- التطبيق يعمل دون اتصال بعد تحميله مرة من عنوان HTTPS.

## ملاحظات
- الأوزان الافتراضية مبنية على آخر أوزان مسجلة، وليست توصية إلزامية لاستخدامها في كل مجموعة.
- 14 كجم للبايسبس كانت لمجموعة واحدة فقط؛ و18 كجم لـ Seated Row يحتاج تأكيدًا؛ و5 كجم للترايسبس يوم الثلاثاء لم يكن بتكنيك مريح.
